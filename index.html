Welcome to TAPER

The sample paper below is already translated into every language, so you can try the reader right now, with no API key and no credits.

  1. Make your plan. Your language, start date and how many weeks. Translate and Read both follow it.
  2. Add a model. Paste an API key and choose a translator and verifier.
  3. Translate a paper. Upload the LaTeX source (.zip). It is translated into your plan's language.
  4. Read it. The paper opens at your plan's level for this week.
