Welcome to TAPER

The sample paper below is already translated into every language, so you can try the reader right now, with no API key and no credits.

  1. Add a model. Paste an API key and choose a translator and verifier.
  2. Make your plan. Your language, start date and how many weeks.
  3. Translate a paper. Upload the LaTeX source (.zip), or try the sample.
